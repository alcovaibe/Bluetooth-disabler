## Bluetooth Disable 1.4.3 — предварительная версия

В этом обновлении переработана навигация Android-приложения:

- Новое плавающее нижнее меню с пятью пунктами: **Тема**, **Язык**, **О приложении**, **Кавермод**, **Проверка обновлений**.
- Активный пункт выделяется синим цветом, добавлены плавные переходы.
- Новый значок Cover Mode; выбор значка приложения перенесён из главного экрана в нижнее меню.
- Удалено боковое меню (Navigation Drawer).
- Добавлено обновлённое пошаговое знакомство с интерфейсом и кнопки «Далее» и «Готово».

Это **prerelease** для тестирования перед стабильным выпуском. Стабильной остаётся версия 1.4.2.
