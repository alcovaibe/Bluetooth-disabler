## Bluetooth Disable 1.4.3 — стабильный релиз

В этом обновлении переработана навигация Android-приложения:

- **Перевыпуск сборки 37:** нижняя навигация теперь содержит только пять иконок без подписей. Высота панели уменьшена до **64 dp**; локализованные названия сохранены для TalkBack и обучения.

- Плавающее нижнее меню с пятью пунктами: **Тема**, **Язык**, **О приложении**, **Кавермод**, **Проверка обновлений**.
- Активный пункт выделяется синим цветом, добавлены плавные переходы.
- Новый значок Cover Mode; выбор значка приложения перенесён из главного экрана в нижнее меню.
- Удалено боковое меню (Navigation Drawer).
- Добавлено обновлённое пошаговое знакомство с интерфейсом и кнопки «Далее» и «Готово».

**Версия 1.4.3 — текущая стабильная (Latest).** Обновлённый подписанный APK имеет `versionCode 37`; ссылка на скачивание сохранена. Этот выпуск заменяет 1.4.2 в качестве последней стабильной версии.

## Bluetooth Disable 1.4.3 — stable release

- **Reissued build 37:** the bottom bar is now icon-only, with a **64 dp** height; localized labels remain available to TalkBack and onboarding.

- Floating five-item bottom navigation: **Theme**, **Language**, **About**, **Cover Mode**, **Check updates**.
- Blue active-item highlight and animated transitions.
- New Cover Mode icon and relocated launcher-icon selector.
- Removed the navigation drawer.
- Updated onboarding with **Next** and **Finish** buttons.

**Version 1.4.3 is the current stable (Latest) release.** Its signed APK uses `versionCode 37`, with the existing download URL preserved. It supersedes 1.4.2 as the latest stable version.
