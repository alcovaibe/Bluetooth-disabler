# Gallery Cover Mode

## Назначение

Режим «Галерея» маскирует Bluetooth Disable под локальную приватную галерею. После активации launcher открывает Gallery Cover Mode, а основной интерфейс Bluetooth Disable доступен через заранее выбранную фотографию и секретную последовательность нажатий либо через аварийное восстановление.

## Возможности

Текущая реализация поддерживает:

- импорт изображений через системный Android Photo Picker;
- копирование выбранных изображений во внутреннее хранилище приложения;
- группировку фотографий по датам;
- полноэкранный просмотр;
- листание фотографий;
- масштабирование;
- избранное;
- автоматический альбом «Избранное»;
- пользовательские альбомы;
- добавление фотографий в альбомы;
- удаление;
- поворот и обрезку;
- просмотр информации о фотографии;
- светлую и тёмную темы.

После импорта локальная копия не зависит от исходного файла в системной медиатеке.

## Настройка скрытого доступа

1. Пользователь выбирает режим «Галерея» и подтверждает переход.
2. При необходимости импортирует фотографии через Photo Picker.
3. Выбирает одну фотографию как секретную.
4. На специальной панели задаёт последовательность из **трёх разных зон**.
5. Повторяет последовательность для подтверждения.
6. После совпадения обеих последовательностей режим активируется.

Доступны пять зон:

- верхняя левая;
- верхняя правая;
- центр;
- нижняя левая;
- нижняя правая.

Повтор одной и той же зоны внутри трёх нажатий недопустим. Всего существует 60 допустимых последовательностей. При вводе в активном режиме между нажатиями допускается не более 5 секунд.

## Открытие Bluetooth Disable

Необходимо открыть секретную фотографию и выполнить настроенную последовательность из трёх зон. Проверка привязана одновременно к идентификатору фотографии и последовательности.

Секретная последовательность не хранится в открытом виде. `GalleryAccessManager` сохраняет HMAC-SHA256, рассчитанный с неэкспортируемым ключом Android Keystore.

## Аварийное восстановление

На главном экране Gallery Cover Mode удерживайте заголовок «Галерея» **3 секунды**. После этого запускается системная аутентификация Android. После успешной проверки пользователь подтверждает сброс маскировки.

Если Quick Settings tile уже добавлен, Bluetooth Disable также можно открыть через плитку.

Отмена аутентификации или подтверждения не изменяет активный режим.

## Хранение и шифрование

Импортированные фотографии, миниатюры и служебные данные хранятся локально. Gallery storage использует шифрование AES-256-GCM с ключами Android Keystore. Правило скрытого доступа использует отдельный HMAC-SHA256 ключ.

Приложение имеет разрешение `INTERNET` для отдельного просмотра политики конфиденциальности. Cover Mode «Галерея» не отправляет изображения на сервер.

Данные исключены из Android backup и device-to-device transfer. `DeviceTransferGuard` дополнительно сбрасывает перенесённое состояние, если app-private файлы были скопированы на другое устройство без соответствующего неэкспортируемого Keystore-ключа.

## Основные компоненты

- `GalleryCoverActivity` — контейнер режима и recovery flow;
- `GalleryCoverSetupActivity` — выбор секретной фотографии и последовательности;
- `GalleryViewModel` — состояние интерфейса;
- `GalleryRepository` — импорт, хранение и операции с изображениями/альбомами;
- `GalleryCipher` — шифрование gallery data;
- `GalleryAccessManager` — HMAC-проверка скрытого доступа;
- `GalleryAccessPolicy` и `GallerySequenceDetector` — правила последовательности и тайм-аут.

## Проверки

Для Gallery Cover Mode есть unit- и instrumentation-тесты, включая:

- проверку 60 допустимых трёхзонных последовательностей;
- отклонение повторяющихся зон;
- сброс последовательности по тайм-ауту;
- импорт и persistence зашифрованных данных;
- восстановление состояния после перезапуска;
- навигацию cover/main;
- recovery flow.

Instrumentation-тесты запускаются общей CI-матрицей Android API 26–36.
