# Gallery Cover Mode

## Назначение

Режим «Галерея» маскирует Bluetooth Disable под локальную приватную галерею. После активации launcher открывает Gallery Cover Mode, а основной интерфейс Bluetooth Disable доступен через аварийное восстановление.

## Возможности

Текущая реализация поддерживает:

- импорт изображений через системный Android Photo Picker;
- копирование выбранных изображений во внутреннее хранилище приложения;
- группировку фотографий по датам;
- полноэкранный просмотр;
- листание фотографий;
- масштабирование;
- избранное;
- автоматический альбом «Избранное»;
- пользовательские альбомы;
- добавление фотографий в альбомы;
- удаление;
- поворот и обрезку;
- просмотр информации о фотографии;
- раскрытие и скрытие панели действий стрелкой с сохранением состояния при листании;
- светлую и тёмную темы.

После импорта локальная копия не зависит от исходного файла в системной медиатеке.

## Настройка

1. Выберите режим «Галерея» и подтвердите переход.
2. При необходимости импортируйте фотографии через Photo Picker.
3. Нажмите «Включить режим Галерея». Фотографии для активации не обязательны.

Обычный вход по секретному снимку и последовательности тапов удалён. Старые правила входа и их ключ очищаются при обновлении без удаления фотографий и альбомов.

## Аварийное восстановление

На главном экране или в просмотре фотографии Gallery Cover Mode удерживайте заголовок «Галерея» **3 секунды**. После этого запускается системная аутентификация Android. После успешной проверки пользователь подтверждает сброс маскировки.

Если Quick Settings tile уже добавлен, Bluetooth Disable также можно открыть через плитку.

Отмена аутентификации или подтверждения не изменяет активный режим.

## Хранение и шифрование

Импортированные фотографии, миниатюры и служебные данные хранятся локально. Gallery storage использует шифрование AES-256-GCM с ключами Android Keystore.

Приложение имеет разрешение `INTERNET` для отдельного просмотра политики конфиденциальности. Cover Mode «Галерея» не отправляет изображения на сервер.

Данные исключены из Android backup и device-to-device transfer. `DeviceTransferGuard` дополнительно сбрасывает перенесённое состояние, если app-private файлы были скопированы на другое устройство без соответствующего неэкспортируемого Keystore-ключа.

## Основные компоненты

- `GalleryCoverActivity` — контейнер режима и recovery flow;
- `GalleryCoverSetupActivity` — импорт фотографий и включение режима;
- `GalleryViewModel` — состояние интерфейса;
- `GalleryRepository` — импорт, хранение и операции с изображениями/альбомами;
- `GalleryCipher` — шифрование gallery data;
- `GalleryAccessManager` — очистка устаревших правил скрытого входа.

## Проверки

Для Gallery Cover Mode есть unit- и instrumentation-тесты, включая:

- активацию без секретной фотографии и очистку старого правила входа;
- кеширование превью с ограничением по памяти;
- импорт и persistence зашифрованных данных;
- восстановление состояния после перезапуска;
- навигацию cover/main;
- recovery flow.

Instrumentation-тесты запускаются общей CI-матрицей Android API 26–36.
