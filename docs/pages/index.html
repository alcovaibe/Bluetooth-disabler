О приложении

Приложение решает проблему принудительного ограничения Bluetooth. Для этого используется Android Device Owner, а не root.

Возможности

Bluetooth restriction
Quick Settings Tile

Gallery Cover
Локальное хранение
Нет облачной синхронизации

Cover Mode

Изменяет внешний вид и способ входа. Не усиливает системную защиту Bluetooth.

Device Owner

Шаг 1: QR provisioning
Шаг 2: ADB provisioning
Шаг 3: проверка политики

Системные требования

Android 8.0+. Device Owner требуется для полной блокировки Bluetooth. Root не нужен.

Безопасность

Open source. Нет рекламы. Данные остаются на устройстве. Backup данных приложения отключён.
