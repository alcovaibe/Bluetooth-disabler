О приложении

Иногда обычных разрешений Android недостаточно для полного ограничения Bluetooth. Bluetooth Disable использует Android Device Owner для применения системной политики без root-доступа.

Системные требования

  • Android 8.0+
  • Device Owner требуется для полной блокировки Bluetooth
  • Root не требуется
  • Первичная настройка обязательна
  • Cover Mode работает отдельно

Безопасность и конфиденциальность

  • Open source
  • Нет рекламы
  • Данные остаются на устройстве
  • Нет отправки пользовательских данных
  • Backup данных приложения отключён
  • Device Owner используется только для Bluetooth policy

FAQ

Зачем нужен Device Owner?

Он позволяет применять системные политики Android.

Почему нельзя использовать обычное разрешение?

Обычные разрешения не дают полный контроль политики Bluetooth.

Нужен ли root?

Нет.

Работает после перезагрузки?

Да, пока сохраняется Device Owner.

Можно ли удалить приложение?

Да, после удаления Device Owner.

Собираются ли данные?

Нет.
