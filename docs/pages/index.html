О приложении

Bluetooth Disable решает задачу ограничения Bluetooth на Android. Вместо root используется Android Device Owner для применения системной политики.

Системные требования

Android 8.0+. Device Owner обязателен для полной блокировки Bluetooth. Root не требуется.

Безопасность

Open source. Нет рекламы. Данные остаются на устройстве. Отправка пользовательских данных отсутствует.
